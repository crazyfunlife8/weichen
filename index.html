PROJECT

彰化員林日照中心

整間的冷氣從進場到收工。長輩在裡面運動，風不能直直對著人吹，所以大教室用天花板嵌入式，小間的用壁掛。

  1. 機器進場嵌入式室內機一車一車送到現場
  2. 室外機上牆兩個師傅兩把梯子一起抬上去，對準支架再鎖
  3. 天花板嵌入式吊上去先抓水平，歪一點冷凝水就排不乾淨
  4. 小間的用壁掛空間不大，一台壁掛就吹得到
  5. 室外機排整齊不是為了好看，以後回來保養手才伸得進去
PROJECT

新房子裝潢 天花板裡的冷氣

每間房間都要冷氣，又不想看到冷氣。主機和風管全部吊進天花板，木工封板之後只看得到一條出風口。

  1. 主機吊進天花板吊歪了，以後冷凝水排不乾淨
  2. 風管分到每一間一台主機接好幾條風管，每個房間都有出風口
  3. 出風口接起來縫封好，冷風才不會漏在天花板裡
  4. 封板前最後檢查封起來就看不到了，管路線路再看一次
PROJECT

新大樓交屋 一戶一戶裝

一次裝好幾戶，機器先推到門口排好。每一戶都抽真空、試吹，沒問題才算交屋。

  1. 機器進場一戶一戶的機器先推到門口排好
  2. 銅管現場彎轉角用彎管器慢慢彎，折到了冷媒就跑不順
  3. 裝好先抽真空管子裡的空氣和水氣抽乾淨，冷媒才放進去
  4. 室外機靠牆排好陽台留走道，以後保養人才進得去
  5. 開機試吹一間一間開起來吹，沒問題才收工

FAQ

常見問題

服務範圍到哪裡？

中壢（含內壢）、平鎮、楊梅、桃園、八德、大園（含青埔）、龜山、蘆竹（含南崁）、新屋、觀音，還有新竹、三重都有跑。其他地區先 LINE 問，車馬費 300 起。

可以開發票嗎？

可以，帷宸冷氣空調統一編號 61316527。

價格怎麼算？

依機型、樓層、管線長度、現場狀況不同，先傳照片給我們，看過再跟你說。

濾網要多久洗一次？

能源署建議每兩週洗一次。打開前面板，濾網往上推再往下拉就拿出來了，從背面用水沖，陰乾再裝回去。濾網以外的鰭片、風扇、接水盤要拆機才洗得到。

冷氣滴水是冷媒不夠嗎？

比較常是排水管堵住或裡面太髒。冷氣開著時去看室外的排水管，有在滴水是正常的，一滴都沒有多半是堵住了，這種要拆機清。
